# ПОШАГОВАЯ ИНСТРУКЦИЯ: Как опубликовать сайт в интернете
## Для тех, кто делает это впервые

---

## Что вообще нужно, чтобы сайт заработал?

Представьте, что сайт — это магазин. Чтобы он работал, нужно 3 вещи:

1. **Адрес магазина (ДОМЕН)** — это название, по которому люди вас находят. Например: `moy-sait.ru`. Это как вывеска на улице.
2. **Помещение магазина (СЕРВЕР)** — это компьютер, который работает 24/7 и показывает ваш сайт всем, кто заходит по адресу.
3. **Товар в магазине (ФАЙЛЫ САЙТА)** — это сам сайт, который мы сделали.

В этой инструкции мы пошагово создадим все 3 вещи.

# ЧАСТЬ 1. Покупаем адрес (домен)

## Шаг 1. Регистрируемся на сайте для покупки домена

**Домен** — это адрес вашего сайта в интернете (например: `google.com` или `yandex.ru`).

Рекомендую покупать домен в российских сервисах — проще оплачивать и поддержка на русском.

### Вариант 1: REG.RU (рекомендую)
1. Откройте браузер и зайдите на **https://www.reg.ru**
2. Нажмите кнопку **"Войти"** в правом верхнем углу
3. Нажмите **"Создать аккаунт"**
4. Введите:
   - Ваш e-mail
   - Придумайте пароль
   - Отметьте галочку "Я согласен"
   - Нажмите **"Зарегистрироваться"**
5. Зайдите в свою почту, найдите письмо от REG.RU и нажмите ссылку подтверждения

### Вариант 2: RU-CENTER (nic.ru)
1. Зайдите на **https://www.nic.ru**
2. Нажмите **"Регистрация"**
3. Заполните форму (e-mail, пароль)
4. Подтвердите почту

---

## Шаг 2. Выбираем и покупаем доменное имя

1. На главной странице REG.RU вы увидите большое поле поиска с текстом **"Поиск доменов"**
2. Введите желаемое название. Например: `lawyers-registry` или `reestr-yuristov`
3. Нажмите кнопку **"Подобрать"** или Enter
4. Система покажет доступные варианты:
   - `lawyers-registry.ru` — около 200-300 ₽/год
   - `lawyers-registry.com` — около 800-1000 ₽/год
   - `reestr-yuristov.ru` — около 200-300 ₽/год
5. Выберите подходящий вариант и нажмите **"В корзину"**
6. Нажмите **"Оформить заказ"**
7. На странице оформления:
   - Выберите **"Физическое лицо"** (если покупаете для себя)
   - Введите свои паспортные данные (требование закона)
   - Выберите способ оплаты (банковская карта)
   - Нажмите **"Оплатить"**
8. Введите данные карты и подтвердите оплату

**Важно:** Запишите куда-нибудь:
- Какой домен купили
- Логин и пароль от REG.RU

## Шаг 4. Создаём сервер

2. Нажмите кнопку **"Создать"** или **"Создать сервер"**

# ЧАСТЬ 3. Подключаемся к серверу

## Шаг 6. Устанавливаем программу для подключения

Нужна специальная программа, чтобы "зайти" на удалённый компьютер (сервер). Эта программа называется **терминал** или **SSH-клиент**.

### Если у вас Windows:
1. Откройте **Microsoft Store** (магазин приложений)
2. В поиске введите: **PuTTY**
3. Нажмите **"Установить"** на приложении PuTTY
4. Дождитесь установки

ИЛИ используйте встроенный терминал:
1. Нажмите правой кнопкой на кнопку "Пуск"
2. Выберите **"Терминал"** или **"Windows PowerShell"**

### Если у вас Mac:
1. Нажмите **Cmd + Пробел**
2. Введите: **Terminal**
3. Нажмите Enter — откроется терминал

### Если у вас Linux:
1. Нажмите **Ctrl + Alt + T** — откроется терминал

---

## Шаг 7. Подключаемся к серверу через терминал

### Для Windows (PowerShell/Терминал):
В окне терминала введите команду:
```
ssh root@XXX.XXX.XXX.XXX
```
(замените XXX.XXX.XXX.XXX на IP-адрес вашего сервера из шага 5)

Нажмите **Enter**.

Система спросит:
```
Are you sure you want to continue connecting (yes/no)?
```
Введите `yes` и нажмите Enter.

Затем введите пароль от сервера (из шага 5) и нажмите Enter.

**Важно:** При вводе пароля символы не отображаются (это нормально). Просто введите пароль вслепую и нажмите Enter.

Если видите что-то похожее:
```
root@vps12345:~# 
```
— значит, вы успешно подключились! 🎉

### Для Mac/Linux:
Точно так же — откройте Terminal и введите:
```bash
ssh root@XXX.XXX.XXX.XXX
```
(замените XXX.XXX.XXX.XXX на ваш IP)

Введите `yes`, затем пароль.

# ЧАСТЬ 4. Устанавливаем программы на сервер

Теперь мы внутри сервера. Всё, что вы вводите — выполняется на удалённом компьютере.

## Шаг 8. Обновляем систему

Введите команду (копируйте и вставляйте):
```bash
apt update && apt upgrade -y
```

Нажмите Enter. Это обновит систему. Подождите 2-3 минуты.

**Что мы сделали:** Обновили список доступных программ и установили обновления безопасности.

---

## Шаг 9. Устанавливаем Node.js (для запуска сайта)

Введите по очереди эти команды (после каждой нажимайте Enter):

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
```

Подождите 30 секунд. Затем:

```bash
apt install -y nodejs
```

Подождите 1 минуту. Проверьте установку:
```bash
node -v
```

Должно показать что-то вроде: `v20.18.0` — это версия Node.js. Если видите версию — всё хорошо!

---

## Шаг 10. Устанавливаем MySQL (база данных)

Введите команду:
```bash
apt install -y mysql-server
```

Подождите 1-2 минуты.

Запустите настройку безопасности:
```bash
mysql_secure_installation
```

Система задаст вопросы. Отвечайте так:
1. `Enter password for user root:` — просто нажмите Enter (пароля пока нет)
2. `Set root password?` — нажмите **Y**, затем Enter
3. `New password:` — придумайте и введите пароль для MySQL, нажмите Enter
4. `Re-enter new password:` — повторите пароль, нажмите Enter
5. `Remove anonymous users?` — нажмите **Y**, затем Enter
6. `Disallow root login remotely?` — нажмите **Y**, затем Enter
7. `Remove test database?` — нажмите **Y**, затем Enter
8. `Reload privilege tables?` — нажмите **Y**, затем Enter

**Запишите пароль от MySQL!** Он понадобится позже.

---

## Шаг 11. Создаём базу данных

Введите:
```bash
mysql -u root -p
```

Введите пароль от MySQL (который только что создали).

Вы увидите приглашение `mysql>`. Это значит, вы внутри базы данных.

Теперь по очереди введите эти команды (после каждой нажимайте Enter):

```sql
CREATE DATABASE lawyers_registry CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

```sql
CREATE USER 'registry_user'@'localhost' IDENTIFIED BY 'придумайте_пароль_здесь';
```

```sql
GRANT ALL PRIVILEGES ON lawyers_registry.* TO 'registry_user'@'localhost';
```

```sql
FLUSH PRIVILEGES;
```

```sql
EXIT;
```

**Запишите:**
- Имя базы данных: `lawyers_registry`
- Имя пользователя: `registry_user`
- Пароль пользователя: тот, который вы придумали в команде выше

## Шаг 16. Копируем файлы сайта на сервер

Теперь нам нужно загрузить файлы сайта на сервер. Есть несколько способов:

### Способ 1: Загрузка через SCP (команда в терминале)

**На вашем компьютере** (не на сервере!) откройте новое окно терминала и введите:

```bash
scp -r /путь/к/папке/с/сайтом/* root@XXX.XXX.XXX.XXX:/var/www/registry/
```

Где:
- `/путь/к/папке/с/сайтом/` — папка с файлами сайта на вашем компьютере
- `XXX.XXX.XXX.XXX` — IP-адрес вашего сервера

Например (Windows):
```bash
scp -r C:\Users\Ivan\Desktop\registry\* root@185.123.45.67:/var/www/registry/
```

Например (Mac/Linux):
```bash
scp -r ~/Desktop/registry/* root@185.123.45.67:/var/www/registry/
```

Введите пароль от сервера.

### Способ 2: Загрузка через SFTP (программа с окошками)

Если терминал пугает, используйте программу с графическим интерфейсом:

**Для Windows:**
1. Скачайте **WinSCP** с сайта https://winscp.net
2. Установите и запустите
3. Нажмите **"Новое подключение"**
4. Введите:
   - **Файловый протокол:** SFTP
   - **Имя хоста:** IP-адрес вашего сервера
   - **Имя пользователя:** root
   - **Пароль:** пароль от сервера
5. Нажмите **"Соединиться"**
6. В левой части — файлы на вашем компьютере, в правой — на сервере
7. В правой части зайдите в папку `/var/www/registry/`
8. Скопируйте все файлы сайта из левой части в правую

**Для Mac:**
1. Скачайте **Cyberduck** с сайта https://cyberduck.io
2. Установите и запустите
3. Нажмите **"Открыть подключение"**
4. Выберите протокол **SFTP**
5. Введите IP, логин `root`, пароль
6. Перетащите файлы сайта в папку `/var/www/registry/`

## Шаг 24. Настраиваем Nginx

Создаём конфигурацию для вашего домена:

```bash
nano /etc/nginx/sites-available/registry
```

Вставьте следующий текст (замените `vash-domen.ru` на ваш домен):

```nginx
server {
    listen 80;
    server_name vash-domen.ru www.vash-domen.ru;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Сохраните: **Ctrl + O**, **Enter**, **Ctrl + X**.

Активируем конфигурацию:
```bash
ln -s /etc/nginx/sites-available/registry /etc/nginx/sites-enabled/
```

Проверяем конфигурацию:
```bash
nginx -t
```

Должно быть: `syntax is ok` и `test is successful`.

Перезапускаем Nginx:
```bash
systemctl restart nginx
```

# РАЗДЕЛ: РЕШЕНИЕ ПРОБЛЕМ

## Проблема 1: Сайт не открывается по домену

**Проверьте:**
1. Работает ли сайт на сервере:
   ```bash
   curl http://localhost:3000
   ```
   Если видите HTML — сайт работает, проблема в Nginx.

2. Перезапустите Nginx:
   ```bash
   systemctl restart nginx
   ```

3. Проверьте настройки DNS (должно пройти до 24 часов после изменения DNS).

## Проблема 2: Ошибка 502 Bad Gateway

```bash
pm2 restart lawyers-registry
pm2 logs
```

## Проблема 3: Ошибка подключения к базе данных

Проверьте файл `.env`:
```bash
cat .env
```

Убедитесь, что пароль правильный. Проверьте подключение:
```bash
mysql -u registry_user -p -e "SHOW DATABASES;"
```

## Проблема 4: Забыл пароль от сервера

В панели Timeweb Cloud найдите сервер и нажмите **"Сбросить пароль"**.

## Проблема 5: Не могу выйти из nano (редактор)

- **Ctrl + O** — сохранить
- **Ctrl + X** — выйти
- **Ctrl + C** — отмена

Если застряли — нажмите **Ctrl + C** несколько раз, затем **Ctrl + X**.
