# Инструкция по деплою на Railway.app (проще, чем VPS)

## Что такое Railway?

**Railway** — это сервис, который берёт ваш код и сам:
- Собирает сайт
- Устанавливает все программы
- Запускает сервер
- Настраивает базу данных
- Делает HTTPS (бесплатно)

Вам не нужно писать команды в терминале! Всё делается через красивый сайт.

**Стоимость:** ~$6.50/мес (~650 ₽)
- Railway Hobby Plan: $5/мес
- MySQL база данных: $1.50/мес

---

## Шаг 1. Регистрация на Railway

1. Откройте **https://railway.app**
2. Нажмите кнопку **"Start for Free"** или **"Login"**
3. Выберите **"Sign up with GitHub"** (рекомендую — проще всего)
4. Разрешите доступ Railway к GitHub
5. Готово! Вы в панели управления Railway.

---

## Шаг 2. Создаём проект

1. В панели Railway нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Если Railway просит — нажмите **"Configure GitHub App"** и выберите ваш репозиторий (или все репозитории)
4. В списке найдите ваш репозиторий с сайтом и нажмите на него
5. Railway автоматически начнёт сборку — подождите 2-3 минуты

**Если кода ещё нет на GitHub:**

### Как загрузить код на GitHub (5 минут):

1. Зайдите на **https://github.com/new**
2. В поле **"Repository name"** введите: `lawyers-registry`
3. Оставьте **"Public"** (или "Private" — как хотите)
4. Нажмите **"Create repository"**
5. На открывшейся странице скопируйте команды (блок "...or push an existing repository..."). Там будет что-то вроде:
```
git remote add origin https://github.com/ВАШ_НИК/lawyers-registry.git
git branch -M main
git push -u origin main
```
6. Откройте терминал в папке с сайтом и выполните эти 3 команды
7. Код загружен на GitHub!

---

## Шаг 3. Добавляем базу данных MySQL

1. В панели Railway откройте ваш проект (нажмите на него)
2. Нажмите **"New"** → **"Database"** → **"Add MySQL"**
3. Подождите 1 минуту — Railway создаст базу данных
4. Нажмите на иконку MySQL — откроются настройки базы
5. Перейдите на вкладку **"Variables"**
6. Найдите переменную **"MYSQL_DATABASE"** — скопируйте её значение
7. Найдите переменную **"MYSQL_URL"** — она понадобится

---

## Шаг 4. Настраиваем переменные окружения

1. В панели Railway нажмите на сервис с вашим сайтом (обычно называется как репозиторий)
2. Перейдите на вкладку **"Variables"**
3. Нажмите **"New Variable"** и добавьте переменные:

| Переменная | Значение |
|------------|----------|
| `DATABASE_URL` | Скопируйте значение переменной `MYSQL_URL` из базы данных (шаг 3) |
| `NODE_ENV` | `production` |
| `SESSION_SECRET` | Придумайте любую длинную случайную строку (например: `my-secret-key-12345-abcdef`) |

### Как скопировать MYSQL_URL:
1. Нажмите на сервис MySQL в проекте
2. Перейдите в Variables
3. Найдите `MYSQL_URL`
4. Нажмите на значение — оно скопируется
5. Вернитесь к сервису сайта, в Variables → New Variable → `DATABASE_URL` → вставьте

**Railway автоматически перезапустит сайт** после добавления переменных.

---

## Шаг 5. Применяем миграции базы данных

Нужно создать таблицы в базе данных.

1. В панели Railway нажмите на ваш сервис (сайт)
2. Перейдите на вкладку **"Deployments"**
3. Нажмите на последний деплой (самый верхний)
4. Перейдите на вкладку **"Shell"**
5. Введите команду:
```bash
node --input-type=module -e "import { getDb } from './api/queries/connection.ts'; import { applications } from './db/schema.ts'; console.log('OK');"
```

**Или проще** — используйте Local Terminal:

1. Установите Railway CLI (один раз):
```bash
npm install -g @railway/cli
```

2. Войдите в Railway:
```bash
railway login
```

3. Свяжите с проектом:
```bash
railway link
```

4. Запустите миграции:
```bash
railway run npx drizzle-kit push
```

Или:
```bash
railway run npm run db:push
```

Таблицы созданы!

---

## Шаг 6. Проверяем, что сайт работает

1. В панели Railway нажмите на ваш сервис
2. Перейдите на вкладку **"Settings"**
3. В разделе **"Environment"** → **"Public Domain"** нажмите на ссылку
4. Сайт откроется в браузере!

Если видите сайт — всё работает! 🎉

## Шаг 7. Подключаем свой домен

### Вариант 1: Домен куплен на REG.RU

1. В Railway откройте Settings вашего сервиса
2. В разделе **"Public Domain"** нажмите **"Custom Domain"**
3. Введите ваш домен (например: `ваш-домен.ru`)
4. Railway покажет вам **CNAME** запись для настройки
5. Зайдите в REG.RU → Мои домены → Управление → DNS-серверы
6. Создайте CNAME запись:
   - **Имя:** `@` или `www`
   - **Тип:** CNAME
   - **Значение:** скопируйте из Railway
7. Сохраните и подождите 10-30 минут
8. В Railway нажмите **"Check DNS"**
9. Когда DNS обновится — Railway автоматически настроит HTTPS (SSL)

### Вариант 2: Купить домен прямо в Railway (проще всего)

1. В Railway откройте Settings вашего сервиса
2. В разделе **"Public Domain"** нажмите **"Custom Domain"**
3. Внизу нажмите **"Purchase Domain"**
4. Введите желаемое название
5. Railway покажет доступные варианты и цены
6. Выберите и купите (привяжите карту)
7. Railway автоматически настроит всё (DNS, HTTPS)

## Шаг 8. Обновление сайта

Когда нужно внести изменения:

1. Внесите изменения в код на вашем компьютере
2. Загрузите на GitHub:
```bash
git add .
git commit -m "Описание изменений"
git push
```
3. Railway **автоматически** увидит изменения и пересоберёт сайт (через 1-2 минуты)

## Если что-то пошло не так

### Ошибка "Build failed"
1. В Railway нажмите на деплой (Deploy)
2. Перейдите на вкладку **"Deploy Logs"**
3. Посмотрите ошибку в конце логов
4. Исправьте в коде → загрузите на GitHub → Railway автопересоберёт

### Сайт открывается, но пустой
- Проверьте, что `DATABASE_URL` настроена правильно
- Проверьте логи: вкладка **"Logs"** в Railway

### База данных не подключается
- Убедитесь, что `DATABASE_URL` содержит правильный `MYSQL_URL`
- Проверьте, что миграции применены (шаг 5)

## Сравнение: Railway vs VPS (Timeweb)

| | Railway | VPS |
|--|---------|-----|
| **Сложность** | Низкая (веб-интерфейс) | Средняя (терминал) |
| **Цена** | ~$6.50/мес (~650 ₽) | ~$4/мес (~400 ₽) |
| **Нужен терминал?** | Почти нет | Да, постоянно |
| **MySQL** | Добавляется в 2 клика | Нужно ставить руками |
| **HTTPS** | Автоматически | Нужно настраивать |
| **Обновления** | Авто через GitHub | Руками через терминал |
| **Масштабирование** | Ползунок в вебе | Покупать новый сервер |

**Вывод:** Railway дороже на ~250 ₽/мес, но значительно проще. Если цена критична — используйте VPS. Если важно простота — Railway.
